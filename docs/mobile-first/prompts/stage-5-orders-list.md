# Этап 5. Список заказов

Ветка: `feature/mobile-5-orders-list`. Файлы: `templates/orders/list.html`, `static/app.css`.

## Задача

1. Поиск на всю ширину, `type=search`, иконка лупы внутри поля, отправка по Enter. Кнопку «Поиск» на телефоне скрыть
   визуально (оставить доступной для скринридера), на десктопе оставить. Если есть запрос — кнопка очистки.
2. Фильтры статусов — один ряд с горизонтальным скроллом (`scroll-snap`, без видимого скроллбара; активный чип
   прокручивается в видимую область). Если роутер уже отдаёт количество заказов по статусам — покажи счётчики;
   если нет — **не** добавляй запросы, напиши в отчёте, что для этого нужно.
3. Карточка компактнее, 3 строки: `[модель ........ статус]` / `[SN · дата ........ чипы оплаты]` /
   `[клиент · телефон ........ сумма]`. Вся карточка кликабельна. Длинные имена обрезаются с многоточием.
   Цель — 4–5 карточек на экране 390×844 вместо 2,5. Тексты вроде `SN: —` сохранить (на них есть тесты).
4. Пустое состояние: понятный текст + кнопка «Приёмка» (для ролей, у которых она есть).

## Проверки

`pytest -q`; `python scripts/ui_snapshots.py --name stage5 --compare stage4`.
