# Этап 2. Каркас и навигация

Ветка: `feature/mobile-2-shell`. Файлы: `templates/base.html`, `templates/more.html`, шаблоны страниц (блоки),
`static/app.css`, `app/i18n/*.json`; одна правка в `app/routers/cash.py` (см. п. 3).

## Задача (ширина < 900 px)

1. **Верхняя плашка 52 px:** слева «назад» (только на вложенных страницах: новый `{% block back_url %}` —
   у заказа список заказов, у справочников и админ-страниц `/more`, у форм кассы `/cash`), заголовок текущего экрана
   (новый `{% block page_title %}`, по умолчанию название приложения), справа круглая кнопка с инициалами → `/more#profile`.
   Переключатель языка и «Выход» из плашки на телефоне убрать (на десктопе — как сейчас).
   Внутренний `h1` страницы на телефоне не дублирует заголовок плашки.
2. **Нижнее меню по ролям:** механик — Заказы · Приёмка · Касса · Ещё; админ — Заказы · Приёмка · Касса · Отчёты · Ещё;
   бухгалтер — Касса · Отчёты · История · Ещё (сейчас у бухгалтера нижнего меню нет). «Приёмка» — акцентная центральная.
   Иконки — макрос `icon()` из этапа 1. Подписи в одну строку с обрезкой; проверь на `ka`.
   Пункты — только туда, куда роль уже имеет доступ (сверься с `app/deps.py` и роутерами).
3. **`/more` для всех ролей.** Сейчас `GET /more` в `app/routers/cash.py` закрыт `require_admin` — замени на зависимость
   «любой залогиненный» из `app/deps.py` (это единственная согласованная правка бэкенда). Страница показывает только
   разрешённые роли пункты, сгруппированные: «Работа» (Внести расход, Отчёты), «Справочники» (Клиенты, Кофеварки, Причины,
   Каталог ERP), «Администрирование» (Пользователи, Промо и цены, История заказов, Журнал) и блок `#profile`: имя, роль,
   сервисный центр, язык (та же форма POST `/locale`), выход (POST `/logout`). Строки с иконкой и стрелкой, высота ≥ 48 px.
   Добавь тест: механик и бухгалтер получают 200 на `/more` и не видят ссылок на `/admin/users`; админ видит.
4. **Десктоп ≥ 900 px — как сейчас:** сайдбар админа, top-nav механика и бухгалтера, без нижнего меню.
5. Проставь `page_title` и `back_url` во всех шаблонах страниц.
