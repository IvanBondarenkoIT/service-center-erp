# Этап 7. Админка, справочники и итоговая проверка

Ветка: `feature/mobile-7-admin`. Файлы: `templates/dictionaries/*.html`, `templates/admin/*.html`,
`templates/reports/index.html`, `static/app.css`, `app/i18n/*.json`.

## Задача

1. **Один паттерн для справочников** (клиенты, кофеварки, причины) **и пользователей:** поиск → кнопка «Добавить»
   (раскрывает форму через `<details>`; сейчас форма всегда открыта) → список карточек; тап по карточке раскрывает форму
   редактирования (если она уже встроена в карточку — оставить там, спрятать в `<details>`). Удаление — красная
   вторичная кнопка внутри формы, не рядом с «Сохранить».
2. Таблицы `/admin/users`, `/admin/order-history`, `/admin/audit`, отчёты — через `.table-cards` из этапа 6.
   Цель: `scrollWidth = 390` на всех страницах (сейчас users 539, order-history 427).
3. **История заказов и журнал:** колонка «Детали» — тот же человеческий формат, что на этапе 4 (тот же фильтр/макрос).
   Фильтр периода — как в кассе (свёрнутая строка).
4. Промо и цены, каталог ERP: кнопки синка на всю ширину, поля цен с `inputmode=decimal`.
